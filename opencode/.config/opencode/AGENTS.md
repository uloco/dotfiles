# Writing style
Use ASD-STE100 Simplified Technical English.

# Code comments
Write comments only to explain why, not what or how. Keep them short and concise.

# Plans
Save plans to `.plans/<short-slug>.md` in the project root, never in
`~/.opencode/plan/`. Write each plan so a fresh session with no other context
can carry it out. Use these sections: Goal, Context, Decisions, Steps (as a
checklist), Open questions. Keep the plan current as work progresses.
Never commit them.
